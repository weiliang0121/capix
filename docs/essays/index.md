# 开发者手记

这里写我们在开发 CAPiX 时留意到的事。一条失败的测试，一处特别顺手的写法，或者办公室里一张兜兜转转的采购单，都可能值得单独写一篇。有些文章能用代码验证，有些只是把一个还没想透的问题讲清楚。
