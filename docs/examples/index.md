# 按主题实践

第一次使用，建议先走完[便签助手教程](../guide/getting-started.md)：运行、拆解并扩展同一个项目。这里的例子用于继续尝试某一种能力，可以根据自己的问题选择。

| 你想做什么                             | 从哪里开始                                 | 运行后关注什么                             |
| -------------------------------------- | ------------------------------------------ | ------------------------------------------ |
| 把普通操作接入节点，组合顺序或动态步骤 | [结构与资源](./structure.md)               | 输入如何经过成员，资源在哪里供给           |
| 组织业务内容，调整本次使用的材料       | [实体与视图](./content.md)                 | 已读取的值、当前内容与视图成员分别如何变化 |
| 让模型选工具，订阅输出或记录过程       | [工具、输出与记录](./runtime.md)           | 真实工具反馈、输出订阅和调用事实           |
| 给现有项目加一个用途                   | [教程：查询便签](../guide/notes-extend.md) | 新节点能否读取同一实体中新写入的内容       |

## 运行与核对

这些示例在 Node.js 中运行，只使用 CAPiX 公开包和示例自己的业务对象。统一检查只走离线路径；页面中的源码直接来自 `examples/`，不在浏览器中启动框架或调用模型。

```sh
pnpm build
pnpm examples:check
```

检查器逐个启动独立 Node.js 进程。示例中的断言核对结果、实体状态或输出事件；工厂模块由检查器显式调用，模块导入成功本身不算通过。

单个例子也可通过 `node examples/view.mjs` 等命令运行。`dictionary.mjs` 与 `presets.mjs` 导出工厂，检查器会构造 Runner 并实际运行。`entities/domain.mjs` 与 `view/skills.mjs` 是组合示例使用的辅助模块，不作为空运行入口计数。

这些教学例子不承诺持久化、跨进程排他、外部效果幂等或任意位置恢复；具体边界由 [当前契约](../README.md)定义。
