# UI primitives

Button, Badge, Dialog, Tabs, Input, Textarea and Card are copied from the official [shadcn/ui new-york registry](https://ui.shadcn.com/r/styles/new-york/button.json), under its [MIT license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md). Each source file records its registry URL. Local adaptations use the consolidated `radix-ui` imports, the application's font scale and Chinese accessible labels. The components remain app-local source; the custom runtime graph is not a shadcn chart.
