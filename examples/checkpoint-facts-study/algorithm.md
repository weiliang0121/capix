# 固定值算法与有界树编码实验

2026-11-06。仅修改实验 `StableValues` 与测试；生产 Invocation、Frame、codec、恢复资格和配置均未改变。本轮把整次固定成本证明替换为逐节点展开摘要，未把实验格式升级为生产格式。

## 本次修正

`own` 每次建立 `WeakMap<source, copy>`，同一次固定中一个源对象只复制一次；活跃祖先用一个 Set，进入时 add、finally 时 delete。先查祖先再查 memo，所以重复的 DAG 边可共享副本，指回祖先仍拒绝。没有按递归层复制祖先 Set。

跨次只保存本实例已完成固定副本的 WeakMap 证据，源对象从不进入该表。整次固定成功后才发布新副本的证据，后继字段失败不会认证未完成父节点。外部冻结对象与另一实例的副本仍重新校验；原源即使浅冻结，下一次固定仍能看到其子对象后续变动。`reuse: false` 禁止跨次复用，但同次 memo 仍保留 DAG 共享。

同实例已认证根直接返回，新增旧正文访问为零，也没有遍历旧元数据关系。每个新对象在子节点完成后保存自己的高度、展开内容摘要与实验格式字节摘要；父节点只读取子摘要。memo 命中免去重复校验和复制，**每条父子边仍必须累加一次展开摘要**。内部节点指向先前访问的共享对象时，也包含那条边的全部展开内容，不会因早先访问而漏算；不相关兄弟不再污染它的摘要。

本轮明确分开三种指标：本次固定实际处理的新对象/字段/文本、失去共享后的逻辑内容规模、特定格式的 UTF-8 字节数。旧正文不再计入新的固定工作；展开内容和字节可以在摘要中超限，`own` 仍可成功，`encode` 再拒绝。旧测试中“组合时 own 因整次证明超限而拒绝”的断言据此改为 encode 拒绝；并增加小子图成功、分批固定编码一致与超大 DAG 不展开的验证。这是明确的预算语义修正，不是维持原接纳集合的性能优化。

## 固定预算与单位

`StableValues({ reuse, limits })` 保留原有用法；limits 只允许非负安全整数，且只能调低下表默认值。构造后复制、冻结并私有保存，外部修改配置不会改变实例预算。

| 参数             |    默认值 | 单位与执行边界                                                                                                           |
| ---------------- | --------: | ------------------------------------------------------------------------------------------------------------------------ |
| maxDepth         |       128 | 根深度为 0，每个属性/数组项到其值增加 1；原始值叶子也计深度。memo/旧副本按当前深度加已知子图高度复核最长路径。           |
| maxObjects       |    10,000 | own：本次新校验的唯一对象/数组数。encode：独立核对展开后的对象数，使同限 decode 也能接纳。                               |
| maxEntries       |    50,000 | own：新对象的自有字段/数组项总数，length 不计，同一新对象只计一次。encode：独立核对展开字段数。                          |
| maxTextUnits     | 1,048,576 | own：新字段名和字符串槽位的 UTF-16 单位；数组索引拼写不计。encode：独立核对展开文本单位。不是 UTF-8 字节数或实际堆内存。 |
| maxEncodedValues |   100,000 | 持久树展开后的带标签值个数，包括根、所有容器及原始值；不包含辅助标签数组自身。                                           |
| maxEncodedBytes  | 8,388,608 | 最终 JSON（包含格式 envelope）的实际 UTF-8 字节数。                                                                      |

预算计费先于该对象的字段递归。数组不再以 Array.from(length) 构造完整期望索引；按键数量和逐项索引验证稠密性。保留 undefined、缺失字段、null、-0，继续拒绝 getter、非枚举字段、Symbol 键、扩展/稀疏数组、custom prototype、环及不支持的活对象。没有新增隐式规范化或 getter/toJSON 执行。

前三个上限的数值被两个阶段分别使用，**固定工作预算不等于展开内容预算**。相同内容的 encode 接纳与编码不因分批固定或共享拓扑而变化；但一次性固定可能超出单次工作预算，而分批固定每次低于预算，这仍会影响 own 是否成功。它不承诺每个已固定根的唯一可达对象总数、所有已持有对象的总堆内存或跨调用配额。深度仍属于根的结构约束：旧子图嵌入新容器时必须按当前深度加已知高度核对，不能靠分批绕过。

## 编码与恢复

持久格式仍为 `stable-value-study@1` 的值树，没有图引用。动态规划已移到 own 的新节点固定过程中：展开值数、对象数、字段数、文本单位和该格式 JSON UTF-8 字节数各自累加，并在对应上限后饱和到 limit + 1。超过上限的摘要只表示“超限”，不再声称是准确长度。高度独立保存。每个对象的摘要有常数个数值，不存子图去重集合或展开树。

同实例对象的 `encode` 只读取根证明并做常数个比较，**预检通过后才构建展开的标签树并 JSON.stringify**。键转义、Unicode、标签及 envelope 都计入字节判断；原始字符串没有对象证据，encode 仍需重新校验并计算其格式字节。预检为 O(1) 不意味着实际输出为 O(1)。

预检读取摘要中的展开对象、entries、文本单位，并核对同限接收端的固定预算。否则小 DAG 可能成功编码，却在同 limits 的 decode 中因失去共享而被拒。由此，固定成功不承诺一定能持久化：保存需要展开后的值也满足预算。旧事实与固定正文在编码拒绝后不改变。

摘要只对本实例固定的上限与 `stable-value-study@1` 有效；私有 WeakMap 不接纳外部摘要，也不跨实例转移。更高上限不能把低上限下的饱和值当作准确尺寸，其他格式不能复用这里的字节证明。生产作者自定义 codec 可以有不同表示和变换，此摘要不能证明其输出大小、纯性或语义等价，也不替代其执行与输出接纳。

`decode` 在 JSON.parse 前限制输入 UTF-8 字节；解析后在创建每个业务子树前验证标签、深度、对象、entries、文本与展开值数量，再经 own 重新隔离和认证。不同实例使用更低预算时仍可以拒绝别处产生的表示。恢复不继承任何进程内证据，也不恢复共享指针拓扑。

## 结果与复杂度

| 反例                                  | 当前观察                                                                                                            |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 9 个对象，8 层双边共享 DAG            | 固定 visits 从旧实现的 767 降为 10（9 对象 + 1 字符串），memo 命中 8 次；持久树仍为 767 个值、18,441 UTF-8 字节。   |
| 101 个对象，100 层共享 DAG            | 固定 visits 102、proofObjects 101、proofEdges 201、proofTextUnits 908；encode 只读根证明 1 次，拒绝且实际展开为 0。 |
| 500 条新边引用同一个 4,000 字符旧正文 | 新增 proofObjects 1、proofEdges 500、proofTextUnits 0；展开文本超限，在 encode 拒绝。                               |
| 从含共享兄弟的根取出内部小子图并包装  | 摘要包含它的共享后代、排除原兄弟；原整次证明误拒的 3 对象包装现在可编码和恢复。                                     |
| 可信值连续转交两次                    | 新增 visits 为 0；禁用跨次复用时为 8，正文含义一致。                                                                |
| 可变源再次固定、环、超深/超宽/超文本  | 分别重新读取源或明确拒绝，不返回旧缓存/部分副本。                                                                   |
| UTF-8 预算刚好相等/少 1 字节          | undefined/null/-0、转义、孤立代理项、Unicode 键/文本、数组和记录均通过边界断言。                                    |

令 V/E 为本次需要新校验的唯一对象/字段数，T 为这些字段名及字符串槽位的文本长度。一个新节点的摘要需要 O(outdegree + 本地文本长度)，不能称为每节点 O(1)；总固定与摘要工作为 O(V + E + T)，不按路径重复复制，可信子节点只查已有摘要。同一对象 memo 命中不再扫描正文，但父边的摘要加法仍计入 E。memo 与新副本占 O(V + E)，逐节点持有的摘要占 O(V)，调用栈与祖先 Set 为 O(depth)，同一可信根复用为 O(1)。新增字节摘要把编码格式的本地文本计量提前到 own；并非所有 own 的实际成本都保持不变。

对象编码预检为 O(1)，后续展开/编码仍为 O(展开值数 + 实际字节)，受内容与字节预算限制。原始字符串编码预检另有 O(字符串长度)。`visits` 计新校验的对象与原始值槽位；`proofObjects/proofEdges/proofTextUnits` 分别计新摘要处理的对象、边和本地文本；`encodingProofReads` 计 encode 读取对象根证明；`encodedValues` 只计通过预检后的实际标签值构建。这些是路径计数，不是完整 CPU 指令、耗时或内存基准。解码仍有 JSON 树、业务树和固定副本的临时分配，成本受输入字节与语义预算约束，没有测量或承诺堆内存上界。

局限：Reflect.ownKeys 必须先枚举源对象全部键，JSON.parse 仍先解析整份已限字节材料；这不是针对恶意 Proxy、篡改全局原型或任意堆耗尽的沙箱。固定图文本预算与 wire 字节预算各司其职；不声称预算是生产配置、跨调用配额、事务或任意执行上界。未迁移生产调用边界、只读类型或生产 codec，未解决 CP refs/state/完整关系检查的历史扫描成本。
